# АйАдмин — MVP ИИ-администратора для стоматологии

Рабочий прототип для продажи собственнику за 2–3 минуты: веб-чат → запись → карточка заявки админу (Telegram + `/admin`).

## 1) Стек (самый быстрый локально)

| Слой | Выбор | Зачем |
|------|--------|--------|
| UI + API | **Next.js 15 (App Router)** | один процесс: чат, админка, API |
| «ИИ» | **Rule-engine** на сценариях | демо без ключей OpenAI, предсказуемый wow |
| База знаний | `data/clinic.json` | прайс, адрес, FAQ, триггеры эскалации |
| Логи/заявки | JSON в `data/runtime/` | ноль Docker/Postgres на демо |
| Эскалация | **Telegram Bot API** | карточка заявки админу (опционально) |

Альтернативы позже: n8n (оркестрация), OpenAI (живая речь), Telegram-бот для пациента (тот же `bot-engine`).


## 2) Запуск

```bash
cd /workspace   # или корень репо
cp .env.example .env.local   # опционально для Telegram
npm install
npm run dev
```

Открыть:
- Чат пациента: http://localhost:3000
- Админка: http://localhost:3000/admin

Критерий готовности (сервер должен быть запущен):

```bash
npm run demo
```

### Telegram (опционально, но для «вау» на встрече)

1. @BotFather → создать бота → `TELEGRAM_BOT_TOKEN`
2. Написать боту /start, узнать свой chat id (@userinfobot) → `TELEGRAM_ADMIN_CHAT_ID`
3. Прописать в `.env.local` и перезапустить `npm run dev`

Без токена заявка всё равно создаётся и видна в `/admin`; в консоли печатается превью карточки.

## 3) Системный промпт бота

Актуальная копия живёт в `src/lib/clinic.ts` (`SYSTEM_PROMPT`). Кратко:

> Вы — АйАдмин, ИИ-администратор стоматологии «Улыбка на Маяковской».  
> Цель: отвечать 24/7 и доводить до записи или передачи человеку.  
> Не ставить диагнозы. Не выдумывать цены. Коротко, на «вы», 1–2 вопроса.  
> Жалоба/агрессия → сразу человек. Нет данных → «уточню у администратора» + эскалация.

## 4) Чек-лист демо для собственника (2–3 мин)

1. Открыть http://localhost:3000 и http://localhost:3000/admin в соседней вкладке.  
2. В чате нажать/написать: **«Сколько стоит чистка и можно завтра в 19:00?»**  
3. Бот даёт цену «от 4 500 ₽», предлагает/фиксирует слот → спросить имя → телефон.  
4. Показать тост «Заявка создана» и карточку на `/admin`.  
5. Второй wow: **«Болит зуб, что делать?»** → без диагноза, срочность, слоты.  
6. Третий: **«Есть ли рассрочка на имплант?»** → эскалация (нет в базе).  
7. Четвёртый: **«Вы меня обманули, хочу жалобу!»** → сразу человек.  
8. Если настроен TG — показать пуш с именем/телефоном/услугой/временем/диалогом.

## 5) Пилот 14 дней (как упаковать в деньги)

**Входит**
- Подключение к сайту (виджет) или Telegram-боту клиники
- База знаний под клинику (прайс, FAQ, врачи, часы)
- Сценарии: цены, боль/срочность, запись, эскалация, жалобы
- Уведомления админу в Telegram + лог заявок
- 1 калибровочная сессия + правки ответов по итогам недели
- Еженедельный отчёт: диалоги → записи → эскалации

**Не входит**
- Интеграция с МИС / DentalPRO / 1С / телефонией (отдельный этап)
- Автоподтверждение SMS/WhatsApp
- Обучение «диагнозам» и медконсультации
- Юридическая ответственность за ответы врача
- Кастомный дизайн виджета под брендбук (можно добавить)

**Оффер**
- Пилот 14 дней: фикс N ₽ (или «бесплатно за доступ к цифрам», если стратегия входа)
- Успех = X% диалогов с контактом / Y заявок в неделю
- Дальше подписка / месяц сопровождения

## Демо-клиника

- **Улыбка на Маяковской** — Москва, ул. Примерная, 10  
- Часы: 09:00–21:00  
- Прайс: гигиена от 4 500 · кариес от 6 000 · имплант от 45 000 · консультация 0–1 500  
- Врачи: терапевт, хирург, ортодонт  
- Слоты: сегодня/завтра по 2–3 окна (генерируются от текущей даты)
