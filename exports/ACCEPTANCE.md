# Критерии приёмки пакета B

Приёмка считается успешной, если выполнены все пункты.

## Функциональные

- [ ] `successful_today` увеличивается **только** при подтверждённом присутствии (`invited` + confirmation `confirmed`)
- [ ] RPC принят, но пользователя нет после 5 проверок → статус failed/unconfirmed, **квота не растёт**
- [ ] `missing_invitees` → отказ, без успеха, интервал аккаунта освобождается
- [ ] Privacy / not mutual → статус `privacy`, без суточного cooldown
- [ ] Техсбой **до** Invite RPC → цель снова `pending`, без cooldown
- [ ] Обрыв **после** маркера → цель остаётся `verifying`, **второй Invite не шлётся**
- [ ] PEER_FLOOD → restrict + ручное восстановление; FloodWait → cooldown по seconds

## SQLite

- [ ] На основном соединении `PRAGMA busy_timeout` ≥ 30000
- [ ] Под параллельным reporter нет стабильных `database is locked` в штатной нагрузке
- [ ] Два воркера не могут одновременно забрать одну pending-цель

- [ ] Не передавались `.session`, прокси, api_hash, токены исполнителю сверх необходимости стенда
