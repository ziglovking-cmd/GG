# Эталонные диалоги Home24

1200 диалогов «гость ↔ менеджер» с разными исходами. Ответы — эталон по script.md (тексты берутся из кода бота, поэтому не расходятся со скриптом). Карточки квартир не выдумываются: на их месте `[КАРТОЧКИ…]`, бот подставляет каталог.

| Файл | Что это |
|---|---|
| `dialogs_home24.jsonl` | все диалоги: реплики, исход, теги, ожидания по каждой реплике гостя |
| `dialogs_home24_sample.md` | 60 диалогов для чтения глазами |
| `finetune_home24.jsonl` | тот же набор в формате дообучения (messages: system/user/assistant) |
| `golden_report_offline.md` | как бот (правила, без ИИ) проходит набор, с примерами ошибок |
| `generate_dialogs.py` | генератор: `python training/generate_dialogs.py --n 1500 --seed 7` |

## Исходы

менеджер (бронь) · подумает · мягкое закрытие · стоп-лист · менеджер (цена) · уже снял другую · гость пропал · показали варианты · жалоба / проблема / оплата / отмена / продление · отказ по правилам · ответ на вопрос.

## Как набор учит бота

1. **Похожие примеры в запрос к ИИ.** `bot/examples.py` на каждое сообщение гостя берёт 1–2 самых похожих реплики с эталонным ответом и кладёт в промпт Groq. Весь набор в промпт не влезет (лимит Groq ~8000 токенов в минуту), а 2 примера — около 500 символов. Выключить: `EXAMPLES_OFF=1`.
2. **Проверка.** `python scripts/eval_golden.py --offline` — бот проходит все 1200 диалогов по правилам за ~10 секунд. С ИИ: `python scripts/eval_golden.py --limit 100` (пауза 8 с между ходами из-за лимита Groq).
3. **Дообучение (на будущее).** `finetune_home24.jsonl` подходит для дообучения моделей, которые это позволяют (OpenAI, Mistral, Together). Groq дообучение не принимает.

Что проверяется у бота: не переспрашивает известное, передаёт менеджеру когда нужно и только тогда, отвечает на попутный вопрос, уважает стоп, без роботских фраз и длинных тире, не повторяет прошлый ответ.

## Дальше

Когда накопятся настоящие переписки (`python scripts/export_dialogs.py`), их лучшие ответы стоит добавить в набор — живые примеры важнее сгенерированных.
