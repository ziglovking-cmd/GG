# Автоответчик Telegram Business

Бот быстро читает переписку с человеком и отвечает **твоим** голосом. На каждый чат — свой режим: старым пишет как ты по истории, новым — как выставишь (подкаты, работа и т.д.).

## Запуск

1. @BotFather → `/newbot`, включи Business Mode. Telegram → Настройки → Telegram Business → Чат-боты: подключи бота, личные чаты, разреши ответы. Не используй токен уже запущенного бота.

2. Скопируй `.env.example` → `.env`: `BOT_TOKEN`, `OWNER_ID` (числовой ID), `AI_API_KEY`, опционально `AI_BASE_URL`, `AI_MODEL`. Сообщения уходят провайдеру при генерации — предупреди собеседника. Не свети `.env` и `bot.sqlite3`.

3. Python 3.10+:
   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt && python bot.py
   ```

4. «Старт» боту → пусть напишут в личку → бот пришлёт ID чата. Ответь вручную пару раз (или залей экспорт), потом `/on ID`.

## Режимы на чат

| Команда | Что делает |
|--------|------------|
| `/chats` | список: вкл/выкл + режим |
| `/on ID` / `/off ID` | автоответы |
| `/mode ID подкат` | флирт/подкаты для новых |
| `/mode ID работа` | деловой тон |
| `/mode ID друг` | свой/тепло |
| `/mode ID холод` | коротко и сухо |
| `/mode ID как_я` | строго по истории этого чата |
| `/mode ID свой текст...` | любой свой бриф |
| `/default подкат` | режим **по умолчанию для новых** чатов |

Пресеты также: `podkat`, `work`, `friend`, `cold`, `me`.

**Логика:** если в чате уже есть твои реплики/импорт — бот читает историю и держит тон к этому человеку. Если чат новый и стоит, например, `подкат` — ведёт лёгкий флирт твоим голосом.

## Стиль «как я»

Telegram Desktop → экспорт чата → JSON (или ZIP с `result.json`), без медиа. Пришли боту файл с **ID собеседника в подписи**. Подтягиваются пары «входящее → твой ответ» (до 80). В запрос: до 28 реплик чата + до 20 пар + профиль длины/эмодзи/регистра.

## Ограничения

Голос/фото/группы/правки — нет. Не чаще ~1 ответа / 8 сек на чат. При ошибке повтора нет. `SKIP` — молчит и пишет тебе в личку.
