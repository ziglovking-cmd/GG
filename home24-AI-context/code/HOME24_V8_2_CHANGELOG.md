# Home24 v8.2 — changelog (RU)

Архив: `/opt/cursor/artifacts/home24_bot_windows_v8_2.zip`

## Что нового

**Тон продажника** — бот говорит как живой, тёплый менеджер посуточной аренды: всегда **«вы»**, коротко и по-человечески, ~1 эмодзи на сообщение (🙂 😊 🏠 ✨ 👍 🙌), без канцелярита. В жалобах/серьёзном — без эмодзи.

Логика v8/v8.1 без изменений: слоты на любом шаге, takeover → тишина, active mode, offline-окна, цены только через менеджера.

**Windows-тесты:** `tests/test_active_mode.py` и `tests/test_presence.py` больше не падают с `NotADirectoryError` на пути вида `...\Temp\tmpXXX\a.db` — temp-БД создаётся как файл внутри каталога; `Store` тоже корректно обрабатывает путь к файлу.

## Примеры фраз (было → стало)

| Место | Было | Стало |
|---|---|---|
| 2-е приветствие (inbound) | Давайте без суеты: подскажите, ищете на даты или пока просто смотрите — подстроюсь. | Подскажите, пожалуйста, на какие даты планируете поездку и сколько будет гостей? С радостью подберу вариант 😊 |
| Уточнение дат | На какие даты примерно смотрите? | Подскажите, пожалуйста, на какие даты планируете поездку? 🙂 |
| Передача менеджеру | Заявку передала. | Отлично, передаю вас коллеге — обычно за 10–15 минут напишет с вариантами и ценами 🙂 |
| FAQ «на ты» | …можно просто на «ты»… | Я из команды Home24 🙂 Подскажу по квартире — напишите, пожалуйста, даты поездки? |
| Каталог | Вот несколько вариантов под ваш запрос: | Подобрала несколько вариантов под вас 🙂 |
| Жалоба | (с эмодзи / сухо) | Мне очень жаль это слышать. Расскажите, пожалуйста, подробнее — сразу передам администратору, разберёмся. *(без эмодзи)* |

Варианты фраз по-прежнему ротируются (несколько пулов в `phrases.py` / `_ASK_VARIANTS`).

## Обновление

Сохраните свой `data/` и `.env`. Распакуйте zip рядом, скопируйте код поверх. `Ctrl+F5` в панели.
