# Home24 v10.26 · 14.11.2026 — как живой менеджер (эталон)

## Что
- После «да» на баллы/услуги: короткий факт + **«Подскажите удобные даты — подберу квартиру?»** (не «Будем ждать!», не дамп районов).
- Когда даты есть, а гости/район пусты: **«На каких условиях планируете остановиться? …»** — как в эталонном диалоге.
- На «хорошо» без дат — мягкое «как надумаете», не закрытие.
