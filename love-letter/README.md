# Для тебя

Нежный публичный сайт-письмо для любимой.

## Настройка

Открой `src/config.ts` и поменяй имя, подпись и тексты.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Ссылка для телефона (GitHub Pages)

Домен `apps.grok.bot` иногда не открывается на мобильных сетях. Зеркало:

1. Открой [Settings → Pages](https://github.com/ziglovking-cmd/GG/settings/pages)
2. **Build and deployment → Source**: `Deploy from a branch`
3. Branch: `gh-pages` / folder: `/ (root)` → Save
4. Через минуту сайт будет здесь: **https://ziglovking-cmd.github.io/GG/**
