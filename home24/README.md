## Запуск

Локально:

```bash
npm install
npm run dev
```

Бот:

```
TELEGRAM_BOT_TOKEN=…
PUBLIC_URL=https://89-111-184-212.sslip.io
python3 bot/main.py
```

Гостевые и менеджерские ссылки только `https://89-111-184-212.sslip.io`. Сайт крутится на VPS `89.111.184.212`. Юниты `home24-web` и бот — в `deploy/`.

База для рассылочного бота с ИИ: `data/mailing-bot/`
(`python3 scripts/export_mailing_db.py` пересобирает из каталога).


## Помощник (RAG)

На гостевых страницах кнопка **«Спросить гид»**.

- Ищет ответ только в инструкции этой квартиры (каталог + FAQ + партнёры Прокшино)
- Если в базе нет факта — честно отказывается и предлагает менеджера
- Генерация через Groq (`GROQ_API_KEY`, модель `GROQ_MODEL`), иначе extractive из найденных кусков

API: `POST /api/rag/ask` `{ "question": "...", "slug": "ferrari" }`
