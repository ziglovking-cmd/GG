# Лабораторная работа Access (лаб3)

Полный пакет по практикуму Кабанова В.А. «Практикум Access» на базе файла **лаб3.accdb**.

## Что сдавать

| Файл | Описание |
|------|----------|
| `output/лаб3.accdb` | База Access (таблицы + данные + запросы) |
| `output/Отчет_БД_Access_полный.docx` | Готовый отчёт №3: шаги, скрины, ответы на вопросы |
| `output/queries.sql` | SQL всех запросов |
| `output/ИНСТРУКЦИЯ.md` | Чек-лист, что ещё кликнуть в Access на Windows |

Исходный черновик отчёта сохранён как `output/Отчет_БД1_исходный.docx`.

## Структура репозитория

- `mocks/` — HTML-макеты окон Access под реальные данные лаб3  
- `shots/` — скриншоты для отчёта  
- `screenshots/` — страницы PDF-практикума  
- `build_report.py` — сборка DOCX  

## Важно

Формы и отчёты в `.accdb` на этой среде (Linux) создать нельзя — в отчёте они оформлены по практикуму + данным БД.  
На Windows в Access пройдите чек-лист из `ИНСТРУКЦИЯ.md` (5–10 минут) и при необходимости замените скрины своими.
