HOW TO RESTORE CONFIG (no secrets in this archive)
1. Copy .env.example if you maintain one, or recreate .env from your password manager / server secrets vault.
   Typical keys are API tokens, Telegram API id/hash, proxy, dashboard auth — take them from your private store, not from chat.
2. Recreate data/ (empty DB will be created by the app on first run, or restore a private backup you keep offline).
3. Re-login Telegram accounts via the project's login flow (login_windows.py / dashboard), do not copy session files into shared archives.
4. Put managers.json / tg_accounts.json from your private backup if needed (managers.example.json is the shape only).
5. pip install -r requirements.txt and run via start.bat / run_windows.bat as in README_WINDOWS.md.
