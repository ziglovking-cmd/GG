# Home24 на Windows — простая инструкция

Один (или несколько) **Telegram-аккаунт компании** пишет гостям.  
**Менеджеры — только пользователи веб-панели**: входят в браузер, ведут диалоги там. Личных Telegram у менеджеров в системе нет.

Роли панели: **ADMIN** и **MANAGER**. Без входа — только форма логина (без бренда и данных).

## Один раз: установка

1. Нужен **Python 3.11**.  
2. Распакуйте бандл → в папке `cmd` → Enter.  
3. Установите зависимости:

```bat
"[REDACTED]\AppData\Local\Programs\Python\Python311\python.exe" -m pip install -U pip
"[REDACTED]\AppData\Local\Programs\Python\Python311\python.exe" -m pip install -r requirements.txt
```

4. В `.env` до первого запуска:

```env
DASHBOARD_ADMIN_USERNAME=admin
DASHBOARD_ADMIN_[REDACTED]
DASHBOARD_[REDACTED]
DAILY_SEND_LIMIT=30
WEEKLY_SEND_LIMIT=210
OUTREACH_MAX_PER_HOUR=4
OUTREACH_MIN_GAP_SEC=240
GROQ_API_[REDACTED]   # ИИ первым; полный список ключей — .env.example
```

При первом запуске в консоли один раз печатается блок **«первый вход в панель»**.  
Менеджеров создаёт только админ в разделе **Пользователи**.

## Каждый день

Дважды щёлкните `start.bat` → `http://[REDACTED]:43125/`

1. Войдите как **админ**.  
2. **Аккаунты** (только админ) — подключите Telegram бота (tdata / QR / код).  
   Обычно достаточно **одного** аккаунта: все **5 менеджеров** делят его (как раньше).  
   При необходимости — до **5 физических SIM компании** на этом же ПК/сети (**без прокси**, без ротации IP).  
   Каждый аккаунт привязан к одному веб-менеджеру: его клиенты пишутся и отвечаются **только** с этой SIM.  
   Капы дня/недели на аккаунт **main** — **30/день и 210/неделя**. Панель не даст поднять main выше. При первом запуске нового кода старый `data\tg_accounts.json` копируется в `tg_accounts.json.bak-limits`, затем main срезается до 30/210.  
3. **Пользователи** — создайте **5 веб-менеджеров** команды (пример: Анна, Иван, Мария, Олег, Елена) — временный пароль или ссылка-приглашение.  
4. **Настройки** — дневной/недельный кап, доли менеджеров в очереди.  
5. Менеджер входит в панель → сразу видит своих клиентов и входящие.  
   Ответ с панели уходит **с аккаунта бота**; в диалоге видно, кто из менеджеров написал.  
   Перехват / возврат боту — по каждому диалогу.  
   Уведомления, звук и бейджи непрочитанного — **в панели**, не в Telegram.

Перед первым сообщением бот добавляет клиента в контакты Telegram, кэширует user id.  
Если номера нет в Telegram — статус **«нет в Telegram»**.

### Лимиты и доли (команда из 5 менеджеров)

- День / неделя на **основной** аккаунт бота: **30 / 210**, пауза 240 с, не больше 4 первых сообщений в час, окно 10:00–20:00 МСК  
- Потенциал в настройках: **210 × 6 = 1260**  
- Доли менеджеров считаются от фактического капа аккаунта (сейчас 30), не от старых 172  
- Число активных меняется динамически: отключили менеджера — его доля уходит остальным  
- Кастомные доли задаёт админ в **Настройки**  
- FloodWait / PeerFlood / отзыв сессии — аккаунт **paused** с предупреждением; клиентов с него **не** перекидывают на другой аккаунт  
- Один клиент → один менеджер и один Telegram-аккаунт навсегда (стоп-лист и 14 дней — общие)

Пример `data/managers.json` — см. `managers.example.json` (5 человек).

### Обновление бандла — что сохранить из `data/`

При замене файлов бота **не затирайте** рабочие данные. Сохраните и перенесите из старой папки:

| Файл / папка | Зачем |
|---|---|
| `data/home24.db` | Диалоги, контакты, очередь, мета |
| `data/mailing.sqlite` | Каталог квартир / рассылка |
| `data/managers.json` | Менеджеры, сессии, лимиты |
| `data/tg_accounts.json` | Слоты Telegram-аккаунтов компании |
| `data/dashboard_users.json` | Логины панели (admin/managers), доли, сервисные флаги |
| `data/templates.json` | Общие и личные шаблоны ответов |
| `data/user_prefs.json` | Тема, подпись, уведомления менеджеров |
| `data/session_blacklist.json` | Отозванные сессии (не переподключать) |
| `data/brand/` | Логотип / брендинг панели |
| `.env` | Ключи API, секрет панели, лимиты |

Обычно **не** нужно переносить: `data/qr.png`, `pending_login.json`, `working_proxy.txt`, отчёты `price_*`, `travelline_sync_state.json` (если цены обновляете скриптом).  
`data/templates.json` из нового бандла можно взять только если своих шаблонов ещё нет.

### Доступ из офиса

`DASHBOARD_HOST=0.0.0.0`, длинный `DASHBOARD_SECRET`, порт 43125 в брандмауэре.

## Автозапуск

`install_autostart.bat` / `uninstall_autostart.bat`

## Если сломалось

Ctrl+C → снова `start.bat` → `logs\bot.log`.  
Рассылку бот сам не начинает — только `/send go` или кнопка в панели.
