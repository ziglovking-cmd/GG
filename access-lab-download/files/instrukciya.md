# Практикум Access — чек-лист (лаб3.accdb)

Открывать файл **`лаб3.accdb`** в Microsoft Access (Windows). Отчёт: **`output/Отчет_БД_Access_полный.docx`**.

## Уже есть в базе
- Таблицы: Группы, Дисциплины, Формы контроля, Возможные оценки, Преподаватели, Студенты, Успеваемость
- Запросы: `Список Студентов1`, `Успеваемость студентов`, `Успеваемость студентов_перекрестный`

## Добить в Access (если чего-то нет на вашей машине)

### Запросы (лаб №3)
1. **Список студентов** — простой запрос: Группы+Студенты → Группа, №Зачетки, Фамилия, Имя  
2. **Параметр** — условие `[Введите группу]` (уже близко к `Список Студентов1`)  
3. **Без подчиненных** — мастер: группы без студентов  
4. **Повторы** — мастер по таблице Успеваемость  
5. **Успеваемость студентов** — 3 таблицы (уже есть)  
6. **Перекрёстный** — строки Дисциплины, столбцы Фамилия, значение Оценка (уже есть)  
7. **Группировка** — Count студентов по группам  
8. **По дате** — `>=#01.01.1995# And <=#01.01.2006#`  
9. **ФИО** — `[Фамилия] & " " & Left([Имя];1) & "."`  
10. **Студенты группы** — условие `=[Forms]![Управляющая]![Выберите группу]`

SQL всех запросов: `queries.sql`.

### Формы / отчёты / меню
1. Форма **Студенты** (мастер)  
2. Форма **Успеваемость** с подчинёнными + кнопка на форму Студенты  
3. Отчёт **Студенты** (группировка, нумерация в группе, Count)  
4. Отчёт **Успеваемость студентов**  
5. Свободная форма **Управляющая**: список групп + кнопки запуска объектов  

### Схема данных
- Целостность на всех связях  
- По желанию: каскадное обновление / удаление на связи Группы–Студенты (для скрина)
